# RealAlexandreAI

[English](README.md)

[RealAlexandreAI](https://github.com/RealAlexandreAI) 的 GitHub 个人主页仓库。本仓库只有主页文字，没有源码、配置，也没有安装步骤。

这里公开的工作主要是处理大模型输出的小型 Go 库，以及围绕 [Model Context Protocol](https://modelcontextprotocol.io) 的 agent 工具。账号显示名为 Alexandre@AI。

## 公开仓库

| 仓库 | 是什么 |
| --- | --- |
| [json-repair](https://github.com/RealAlexandreAI/json-repair) | Go 库和命令行工具，修复格式错误的 JSON，包括大模型产出的 JSON。GPL-3.0。Homebrew formula 在 [homebrew-tap-jsonrepair](https://github.com/RealAlexandreAI/homebrew-tap-jsonrepair)。 |
| [io-sankey](https://github.com/RealAlexandreAI/io-sankey) | Go 框架，在异构数据之间做 IO 映射和校验。GPL-3.0。 |
| [featuregate](https://github.com/RealAlexandreAI/featuregate) | 从 [mosn](https://github.com/mosn/mosn) 拆出的 Go feature gate 包。Apache-2.0。 |
| [mcp-interactive](https://github.com/RealAlexandreAI/mcp-interactive) | MCP 服务器，在 agent 工作时收集交互反馈（文字、截图、常用提示词）。Fork。 |
| [mcp-server-tauri-v3](https://github.com/RealAlexandreAI/mcp-server-tauri-v3) | 面向 Tauri v3 应用的 MCP 服务器和桥接插件。hypothesi/mcp-server-tauri 的 fork。MIT。 |
| [public-skills](https://github.com/RealAlexandreAI/public-skills) | 可复制到其他 agent skills 目录的技能。没有许可证文件。 |
| [shannon-statusline](https://github.com/RealAlexandreAI/shannon-statusline) | 已归档。Claude Code 的终端状态栏。npm 包 `shannon-statusline` 已于 2026-10-03 下架。MIT。 |
| [semi-auto-workflow](https://github.com/RealAlexandreAI/semi-auto-workflow) | 占位仓库。没有可安装或运行的源码。GPL-3.0。 |
